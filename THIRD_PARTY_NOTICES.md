# Third-party notices and provenance

## Vendored React runtime

`frontend/vendor/react18.runtime.js` contains React, ReactDOM and Scheduler production modules distributed with the authoring environment's JupyterLab installation, plus a small local module loader. The React and ReactDOM module bodies were not rewritten. React reports version `18.2.0`; ReactDOM reports `18.2.0-next-9e3b772b8-20220608`. **The latter is a prerelease build identifier, not a claim of a current stable ReactDOM release.**

Original local distribution filenames:
- `6540.51c00e890179a4832552.js`
- `961.29c067b15a524e556eed.js`

SHA-256 of the checked-in runtime: `b057524aa6a8c396421be8add9be83c33cf260d5eb6b35a04fc235c850367ae1`

This was an offline authoring accommodation: the environment could not reach npm. No runtime CDN or package install is needed to display the application. The production release gate is to re-vendor matching, maintained, audited React and ReactDOM releases from the official npm distributions, update this provenance record and run both browser suites again. The package-lock file contains no npm dependencies and is **not** a vulnerability audit of the vendored runtime.
